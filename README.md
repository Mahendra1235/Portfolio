# Modern Full Stack Developer Portfolio

## Run locally
1. `npm install`
2. `npm run dev`
3. Open the local Vite URL.

## Customize
- Edit `src/data/content.js` for your name, bio, projects, skills, experience and contact details.
- Replace the profile placeholder in `Hero.jsx` with your own photo if desired.
- Put your CV at `public/resume.pdf`.
- Replace `#` GitHub/demo links in `content.js`.
